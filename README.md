# Flexbox Layout Practice

This project was developed as part of the Factoría F5 software development bootcamp. The main goal was to master **CSS Flexbox** to create a responsive web design.

## 🚀 Objectives
- Use Semantic HTML5 tags.
- Implement a responsive layout using Flexbox (`flex-wrap`, `gap`, `justify-content`).
- Integrate Google Fonts.
- Deploy the project using GitHub Pages.

## 🛠️ Technologies Used
- **HTML5**: Structural markup.
- **CSS3**: Layout and styling (Flexbox).
- **Google Fonts**: Poppins font family.
